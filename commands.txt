Notice that you don't get any autocomplete suggestions for the Deno
namespace. We need to activate the deno extension for this.
Activate it by typing Ctrl + Shift + P to open the VSCode command palette
and search for Deno: Enable. Select the enable option and you should now
have autocompletion activated
